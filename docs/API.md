# API reference

Generated by `tools/gen_api_reference.py` from the public members of the sources. Do not edit by hand.
Conventions: time is counted in ticks, angles are in degrees.
Guide with examples: [MANUAL](MANUAL.md). The classes of `skarph.core` are the engine and are the same on every platform;
the Android platform layer (`skarph.android`) is listed at the end. The desktop layer is described in [MANUAL, section 14](MANUAL.md#14-desktop-windows-linux-macos).
